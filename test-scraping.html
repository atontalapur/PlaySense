Instructions for Testing

  1. Load this page in your browser
  2. Open the PlaySense extension popup
  3. Click "Start Monitoring"
  4. Check the overlay window for detected game data
  5. Look at the browser console for detailed scraping logs
  6. Verify that the extension detects the simulated game data

Expected Behavior:

  • NFL Detection: Should detect "nfl" game type and find touchdown, field goal, pass, etc.
  • MLB Detection: Should detect "mlb" game type and find home run, strikeout, inning, etc.
  • F1 Detection: Should detect "f1" game type and find overtake, pit stop, safety car, etc.
  • Live Detection: Should detect live indicators and score data
  • Close Button: The ✕ button in the overlay should properly close/hide the window
  • Minimize Button: The − button should minimize/expand the overlay
  • Log Button: The 📋 button should toggle between current status and event log

Debugging Tips:

  • Open browser console (F12) to see detailed logging
  • Look for "Close button clicked" messages when clicking the ✕ button
  • Check for any error messages about missing elements
  • Verify that event listeners are being added successfully
