PlaySense Privacy Policy

Last updated: August 27, 2026

What PlaySense does

PlaySense is a Chrome extension that reads ESPN game pages and displays plain-English explanations of live sports events in an overlay on your screen.

What PlaySense sends, and where

To describe a live game, PlaySense requests public game data from two third-party services:

  • ESPN (site.api.espn.com) — public scores and play-by-play for the game page you are viewing. PlaySense sends only the public game identifier from the page URL.
  • OpenF1 (api.openf1.org) — public Formula 1 race-control messages. PlaySense sends only the public session identifier.

These requests contain no personal information, no account identifiers, and no browsing history. PlaySense sends nothing about any page other than the live game you are actively monitoring.

Optional AI explanations

If you choose to save an Anthropic API key, PlaySense sends the play type and the public play description of major plays to Anthropic (api.anthropic.com) to generate a plain-English explanation. No personal information, browsing history, or page content beyond the play description is sent.

Your API key is stored only in this browser via chrome.storage.local. It is never sent anywhere except Anthropic, and the extension author never receives it. Clearing the key in the popup disables this feature immediately; PlaySense then uses only its built-in explanations and contacts Anthropic not at all.

PlaySense limits itself to 500 explanation requests per day to protect you from unexpected usage on your key.

What PlaySense stores

Everything below is stored only in this browser. None of it is transmitted to the extension author, and PlaySense has no server to transmit it to.

In chrome.storage.local, which persists until you remove it:

  • Your Anthropic API key, if you have chosen to save one. Clearing it in the popup deletes it.
  • A count of how many explanation requests have been made today, plus the date it applies to. This is what enforces the 500-per-day limit above.
  • A single flag recording whether you have seen the welcome message.

In chrome.storage.session, which is held in memory and cleared when you close the browser: the identifiers of the plays already shown for each tab being monitored, so that a game is not replayed from the start. These are removed when you stop monitoring or close the tab.

Game events themselves are held in memory for the current session and are discarded when the tab closes.

What PlaySense does not do

No analytics, no tracking, no advertising, no accounts, and no transmission of data to the extension author. PlaySense has no server.
